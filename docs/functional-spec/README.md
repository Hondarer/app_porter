# porter 機能仕様

## この文書群の役割

`functional-spec/` は、利用側または上位設計から見た porter の責務を、機能カテゴリごとに説明する文書群です。  
porter が解決する課題、満たす要件、外部から観測できる振る舞い、前提、保証範囲、適用範囲外を定めます。

機能仕様は、API 設計、実装設計、実装、テストに渡す入力です。  
記載範囲、章立て、要件 ID と UUID の運用は [porter 機能仕様の記載規範](../functional-spec-guideline.md) に従います。

## 文書の位置付け

機能仕様は、関数の一覧、実装方式、テスト方法を扱いません。  
下流成果物は、設計判断または検証対象の根拠を示す必要がある場合に、機能仕様の要件 ID と UUID を参照します。

同じ階層にある機能仕様は、責務の境界または選択方法を説明する場合に相互参照します。

## 機能仕様一覧

| 機能仕様 | porter が担う役割 |
|---|---|
| [基盤 (base)](base.md) | 結果の共通表現、判定の契約、診断出力の入口 |
| [サービス管理 (service)](service.md) | サービスの開始と終了、役割、終了時のメッセージの送出 |
| [構成 (config)](config.md) | 構成の受け取り、既定値、構成の検証 |
| [通信種別 (transport)](transport.md) | 到達範囲の選択、双方向、下位通信の差異の吸収 |
| [セッション識別 (session)](session.md) | 通信の開始の識別、過去の通信の排除、送信元の識別 |
| [メッセージ配送 (delivery)](delivery.md) | 順序の保証、欠落の検知と再送、順序の復元、切断の通知 |
| [メッセージ構成 (message)](message.md) | 大きさの上限、分割と復元、一括送出、圧縮 |
| [死活監視 (health)](health.md) | 疎通の監視、接続と切断の通知、経路単位の通知 |
| [マルチパス (multipath)](multipath.md) | 複数経路の並行利用、重複の排除、経路単位の継続 |
| [通信保護 (security)](security.md) | 機密性と完全性、事前共有鍵、保証しない範囲 |

## 変更時の扱い

porter の機能、外部から観測できる振る舞い、前提、保証範囲、適用範囲外を変更する場合は、対応する機能仕様を先に変更します。  
要件 ID と UUID の追加、維持、廃止は [porter 機能仕様の記載規範](../functional-spec-guideline.md) に従います。
