# 通信種別 (transport) 機能仕様

## 概要

通信種別機能は、利用側が選択できる到達範囲と接続の形態を定め、下位の通信の差異を同一の操作へ統合します。

利用側は、一対一、一対多、多対一の到達範囲を構成で選択します。  
下位の通信がデータグラム型かストリーム型かにかかわらず、送信と受信の手順は同一です。

## 解決する課題

到達範囲ごとに、通信相手の決定方法、待ち受けの方法、接続の有無が異なります。  
利用側がこれらの差を直接扱うと、到達範囲を変更するたびに通信処理を再構築することになります。

また、データグラム型とストリーム型では、境界の有無と接続の管理が大きく異なります。

通信種別機能は、これらの差を通信種別の選択に置き換え、利用側の操作を同一の形式に維持します。

## 到達範囲の選択

到達範囲は、一対一、一対多、多対一の 3 つに分かれます。  
一対多は、あらかじめ決定した集団へ届ける方法と、同一のネットワークへ一斉に届ける方法を含みます。

多対一では、複数の送信元が 1 つの受信側へ送信します。  
受信側は、送信元ごとに区別した識別子とともにメッセージを受け取り、送信元を指定して返信できます。

## 下位通信の違いの吸収

データグラム型とストリーム型のどちらを用いる場合も、利用側は同じ手順で送信と受信を行います。  
ストリーム型では、下位の通信に境界が存在しないため、porter が受信したデータから元のメッセージの境界を復元します。

接続を伴う通信種別では、接続が失われた場合に、構成で指定された間隔で再接続を試行します。  
接続が回復した場合は、通信の確立として利用側へ通知されます。

## 双方向の通信

双方向の通信種別では、通信を開始した側と待ち受けた側の双方がメッセージを送信および受信できます。  
役割の指定は、どちらが通信を開始するかを決定するものであり、送信できる方向を制限しません。

## 送信元の限定

受信側は、受け付ける送信元を構成で限定できます。  
限定の対象外から届いたメッセージは受理されず、受信状態にも影響しません。

## 適用範囲外

- 経路の選択、輻輳制御、帯域の制御など、下位の通信が担う制御
- 名前解決の仕組みそのもの、およびその結果の保持期間の制御
- IPv6 による通信
- 通信継続中における到達範囲の変更

## 前提と制約

一対多の到達範囲は、経路上の機器が該当する転送を許可していることを前提とします。  
転送が許可されない環境では、構成が正しくてもメッセージは届きません。

送信元の限定は、送信元として観測できる情報に基づきます。  
送信元を偽装した通信を排除する手段としては、通信保護機能を使用します。
