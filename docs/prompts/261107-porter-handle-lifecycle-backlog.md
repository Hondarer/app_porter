## BL-001 追加性能評価の実施

### 現状と期待する評価

既存の UDP 24 条件の性能比較と CI #42605427102 は受入済みです。  
設計で予定した次の測定記録は未確認のため、別件で評価結果を補う必要があります。

- N:1 のコールバック内返信と外部スレッド返信の比較
- 低速コールバック時の通知遅延、ピーク メモリ、通知消費後の保持メモリ
- open/close 反復時の通信資源回収、制御オブジェクトの保持量、終了所要時間
- API 遅延の中央値・p95、通知遅延の中央値・p95・p99、ウォーム アップ条件と測定のばらつき
- TCP 予備測定で記録された終了時エラーの修正版での再確認と、比較測定への適用可否

### 摘出契機と見送り理由

2026-11-10 の受入条件照合で、設計の性能評価項目と既存記録の差を確認しました。  
ユーザーは [Q-014](261107-porter-handle-lifecycle-discussion.md#q-014-ci-成功後に残る性能評価の扱い) の A を選択し、指定 CI と既存性能結果を受け入れ、追加評価を別件へ引き継いで本案件を完了しました。  
未確認項目を測定済みと扱う合意ではありません。

### 影響範囲とリスク

専用通知スレッドと通知キュー、ハンドル制御情報の保持が評価対象です。  
低速コールバックや長時間の open/close 反復におけるメモリ保持量、通知遅延、終了時間が定量化されていません。  
通常の UDP 比較結果を、これらの負荷条件や TCP の性能保証へ適用できません。

### 推奨する対応と完了条件

[最終仕様](261107-porter-handle-lifecycle-design.md#性能の測定条件と評価) に沿い、同一環境・設定で比較可能な負荷を用意します。  
新機能の返信経路は外部返信との比較と絶対値を分け、低速コールバックと open/close 反復ではピークと回収後の保持量も記録します。  
TCP の終了時エラーを再確認し、測定条件の問題か製品の問題かを切り分けたうえで比較への適用可否を記録します。  
全項目の測定条件、対象コミット、反復回数、ばらつき、結果と限界を保存し、受入判断を得た時点で対応済みとします。
